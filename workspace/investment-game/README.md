# Investment Game

This directory contains the tablet app and services require to conduct an investment game experiment.

### Getting Started

> [!WARNING]
> This experiment requires a rooted Pepper tablet. If your Pepper tablet is not rooted, follow [Lilith Wittmann's jailbreak guide](https://github.com/LilithWittmann/pepper-tablet-jailbreak/blob/master/README.md).

To run the full system, follow the setup instructions in the respective subdirectories:

- Frontend (Tablet App): See the [README](./frontend/README.md) in `./frontend`
- Backend Services: See the [README](./services/README.md) in `./services`

Please make sure both the frontend and services are properly configured and running for the game to function as intended.
